# WORKOUT VAULT DESCRIPTION :

A static, desktop‑only fitness website built with **HTML, CSS, and JavaScript**.  
The app provides a user‑friendly interface to browse 100+ exercises with detailed instructions, with a responsive design. It is offline‑friendly (no server or API dependency) and hosted on **GitHub Pages**. This project is part of my full‑stack learning journey, showcasing UI styling, form validation, and interactive navigation.

---

## Features :
- 100+ exercises with step‑by‑step instructions along with images.
- Multi‑page layout with smooth navigation.
- Responsive design optimized for desktop screens.
- **Inbuilt stopwatch for tracking sets and rest times.**
- Form validation for workout entries.
- Dropdown menus and footer icons.
- Offline‑friendly (all assets stored locally).
- Clean and aesthetic UI styling.

---

## Tech Stack :
- **HTML5**
- **CSS3**
- **JavaScript**
- **Git & GitHub** (version control + hosting via GitHub Pages)

---

## Usage :
- Browse 100+ exercises with step‑by‑step instructions.
- Filter workouts by muscle group, difficulty, or equipment.
- Use the **inbuilt stopwatch** to track sets and rest intervals.
- Log exercises with validation to avoid duplicate or invalid entries.
- Explore nutrition and fitness tips.
- Manage multiple accounts with linked profiles.
- Works offline on desktop browsers (all assets stored locally).
